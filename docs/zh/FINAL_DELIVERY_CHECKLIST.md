# 最终交付清单

## 1. 功能验收

- [ ] 可以创建 `P-Item` 物料。
- [ ] 可以创建 `P-BOM`，并录入至少 5 条 `P-BOM Item` 明细。
- [ ] `P-BOM Item` 能通过 Link 引用 `P-Item`。
- [ ] BOM 明细中重复物料会被阻止保存。
- [ ] BOM 明细中数量小于或等于 0 会被阻止保存。
- [ ] 表头 `total_qty` 能根据明细数量自动计算。
- [ ] 可以创建 `P-ECO` 并关联 `P-BOM`。
- [ ] ECO 发布后，关联 BOM 的版本号更新为目标版本。
- [ ] ECO 发布后，关联 BOM 状态变为已审核。

## 2. 权限与流程

- [ ] 普通工程师可以创建草稿 BOM。
- [ ] 普通工程师不能提交 BOM。
- [ ] 工程经理可以提交 BOM。
- [ ] ECO Workflow 包含草稿、审核中、已发布。
- [ ] 已发布 ECO 不可编辑。
- [ ] 质量人员只能查看已审核 BOM 和已发布 ECO。

## 3. 报表与 API

- [ ] Query Report 能显示已审核 BOM 的物料构成。
- [ ] 报表可以按成品物料过滤。
- [ ] 报表支持导出 Excel。
- [ ] API Token 可以成功读取 `P-Item` 列表。
- [ ] API Token 可以成功创建一条测试物料。

## 4. 工程化交付

- [ ] 自定义 DocType 位于 `pdm_tutorial` Custom App 中。
- [ ] 关键权限、角色、工作流和字段配置已通过 fixtures 导出。
- [ ] 已执行 `bench migrate` 验证迁移过程。
- [ ] 已执行 `bench clear-cache` 验证配置刷新。
- [ ] 至少有一个单元测试覆盖 BOM 明细校验。
- [ ] 代码已提交到 Git，并包含清晰的提交说明。

## 5. 结课演示

- [ ] 演示从物料创建到 ECO 发布的完整流程。
- [ ] 演示一个失败案例，例如重复物料被阻止。
- [ ] 演示普通工程师和工程经理的权限差异。
- [ ] 演示报表查询和 API 调用结果。
