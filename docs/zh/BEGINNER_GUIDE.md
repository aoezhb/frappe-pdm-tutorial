# 基础导学：术语与学习路线

这份导学是给基础薄弱学员准备的。你不需要一开始就理解所有 Frappe 内部机制，但要先把几个核心词听熟。否则后面的实验会像在看一堆陌生缩写。

## 1. 先理解：我们到底在做什么？

我们要做的是一个微型 PDM 系统。

PDM 可以理解为“产品资料管理系统”。制造企业会在里面维护：

- 物料：比如螺丝、电机、外壳、控制板。
- BOM：一个产品由哪些物料组成，每种物料要几个。
- ECO：工程变更单，比如把电机从 A 型号换成 B 型号。

用一句话说：本课程不是为了做一个漂亮页面，而是为了学习如何把企业里的业务规则变成系统。

## 2. Frappe 是什么？

Frappe 是一个用于构建企业应用的 Web 框架。你可以把它理解为：

- 它帮你生成后台管理界面。
- 它帮你保存数据到数据库。
- 它帮你处理权限、表单、列表、报表、API。
- 你主要负责把业务对象和业务规则描述清楚。

传统开发常常是先建数据库表，再写后端接口，再写前端页面。Frappe 更像是先定义一个 DocType，系统自动帮你生成很多基础能力。

## 3. 最重要的 10 个术语

### DocType

DocType 是 Frappe 中最重要的概念。它可以理解为“业务表单类型”。

例子：

- `P-Item` 是物料表单类型。
- `P-BOM` 是 BOM 表单类型。
- `P-ECO` 是工程变更单表单类型。

如果用数据库语言说，DocType 很像一张表；如果用业务语言说，DocType 是一种单据或主数据。

### Document

Document 是某个 DocType 下面的一条具体数据。

例子：

- `P-Item` 是 DocType。
- `MAT-001 螺丝` 是一条 Document。
- `BOM-001 电机组件 BOM` 是一条 Document。

### Field

Field 是字段，也就是表单上的一个输入项。

例子：

- 物料编号
- 物料名称
- 规格
- 数量
- 生效日期

### Link

Link 是“引用另一个 DocType 的数据”。

例子：BOM 上有一个“成品物料”字段，它应该从 `P-Item` 里面选择，而不是随便手写。这样可以避免有人写“螺丝”，有人写“螺钉”，导致数据混乱。

### Table

Table 是主子表中的“子表”。

例子：一个 BOM 下面有很多明细行：

| 子项物料 | 数量 |
| --- | --- |
| 螺丝 | 4 |
| 外壳 | 1 |
| 电机 | 1 |

这些明细行就适合放在 Table 字段里。

### Controller

Controller 是某个 DocType 背后的 Python 类，用来写保存前校验、提交后联动等逻辑。

例子：保存 BOM 时检查“明细里不能有重复物料”，这就适合写在 Controller 里。

### Client Script

Client Script 是前端脚本，用来处理表单上的即时交互。

例子：用户修改 BOM 明细数量时，页面上立刻刷新“总项数”，不用等保存后才看到。

### Workflow

Workflow 是审批流或状态流转。

例子：ECO 从“草稿”到“审核中”，再到“已发布”。不同状态下，不同角色可以做不同动作。

### Report

Report 是报表。

例子：查询所有已审核 BOM，列出成品物料、子项物料和数量，方便导出给生产或采购部门。

### API

API 是给其他系统调用的接口。

例子：MES 系统想读取物料清单，可以通过 Frappe 的 REST API 获取 `P-BOM` 数据。

## 4. 学习时最容易混淆的地方

| 容易混淆 | 正确理解 |
| --- | --- |
| DocType 和 Document | DocType 是类型，Document 是具体一条数据 |
| Link 和 Table | Link 选一条别的表数据，Table 放多行子表数据 |
| Controller 和 Client Script | Controller 在服务器执行，Client Script 在浏览器表单上执行 |
| Role Permission 和 Workflow | Role Permission 管“谁能做什么”，Workflow 管“单据状态怎么流转” |
| Report 和 API | Report 给人看，API 给系统调用 |

## 5. 最小知识补课清单

如果你觉得吃力，可以先补这些内容：

- Python：变量、函数、类、列表、字典、异常。
- JavaScript：函数、对象、数组、事件。
- SQL：`SELECT`、`WHERE`、`JOIN`。
- Web 基础：浏览器、服务器、HTTP、JSON。
- ERP 基础：主数据、单据、审批、权限、报表。

## 6. 一个贯穿全课的小例子

假设我们要生产一台“小型电机组件”：

- 成品物料：`FG-MOTOR-001 小型电机组件`
- 子项物料：
  - `MAT-SCREW-001 螺丝`，数量 4
  - `MAT-COVER-001 外壳`，数量 1
  - `MAT-MOTOR-001 电机`，数量 1
- BOM：`BOM-FG-MOTOR-001-A0`
- ECO：把电机从 A 供应商型号改成 B 供应商型号，目标版本从 `A.0` 升级到 `A.1`

后面的每个实验，都可以围绕这组数据练习。这样你不是在抽象地学字段和代码，而是在完成一个真实的业务变化。
