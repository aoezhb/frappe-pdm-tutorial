# Contributing

Contributions are welcome.

## Content Guidelines

- Keep the tutorial beginner-friendly.
- Prefer concrete ERP/PDM examples over abstract framework descriptions.
- When adding code, explain the business rule it implements.
- Keep English and Chinese versions structurally aligned when possible.
- Avoid direct claims that low-code means no engineering knowledge is required.

## File Organization

- English documentation lives in `docs/en`.
- Chinese documentation lives in `docs/zh`.
- Code snippets should stay in `CODE_SNIPPETS.md` unless they become a runnable sample app later.

## License of Contributions

## Suggested Pull Request Checklist

- [ ] The change is clear and beginner-friendly.
- [ ] Any new code snippet includes a short explanation.
- [ ] Related English and Chinese docs are updated or the PR explains why not.
- [ ] Links use relative paths.
- [ ] Terminology is consistent with existing files.
